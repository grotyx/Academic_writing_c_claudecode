# Author & Affiliation Profile (Template)

> Copy this file to `profile/authors.md` and replace every `[...]` placeholder
> with your own details. `profile/authors.md` is gitignored — only this
> `example_` template is tracked, so your real author data never leaves your machine.
>
> Referenced when writing the title page (WORKFLOW.md Phase 4). Never type author
> details straight into a manuscript: put them here once, then cite this file.
>
> Keep it current: when an affiliation, ORCID, or grant number changes, edit this
> file rather than the manuscript.

## 표준 보일러플레이트

> 아래 문구는 그대로 재사용 가능하다. 저널 요구 문구가 다르면 해당 저널 섹션에 맞춰 조정할 것.

### AI 사용 고지

```
The authors acknowledge the use of [AI tool name] ([Vendor], [Location]) for English language enhancement during the preparation of this manuscript. After using this tool, the authors reviewed and edited the content as needed and take full responsibility for the content of the publication.
```

> 모델명은 제출 시점에 맞게 업데이트. 저널이 AI 사용 공개를 Methods에 요구하는지 Acknowledgment에 요구하는지 확인할 것.

### 영문 교정

```
We would like to thank [Editing service] ([URL]) for English language editing.
```

### 이해충돌 없음 (표준)

```
The authors declare that they have no competing interests.
```

또는:

```
The authors have no personal, financial, or institutional interest in any of the drugs, materials, or devices described in this article.
```
